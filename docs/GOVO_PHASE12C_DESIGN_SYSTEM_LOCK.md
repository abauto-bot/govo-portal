# GOVO Express Phase 12C — Design System Lock

## Brand Core
GOVO Express = Save Time, Fast Done, All Services In One Place.

## Visual Style
- Premium white background
- GOVO green + deep green + black typography
- Rounded cards
- Soft shadows
- Clean icon system
- Mobile-first app feel
- Logo, app icon, services, hero text, and animations must remain editable

## Main Editable Areas
- Logo / app icon
- Brand colors
- Hero text
- Services list
- Shops categories
- Merchant CTA
- Rider CTA
- Bottom navigation
- Animation speed
- UI radius and shadow
